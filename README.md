# ClassicGamesCollection
A collection of classic games that I'm coding in Java. Originally a fully console application, I am currently updating each game with a visual component.
The following games are in the collection.
1. BlackJack: This game is played with cards. If the player gets a blackJack (jack and ace combination) they automatically win. Dealer and player alternate in this version. If the dealer busts, the player wins. Dealer will stop at any number up to 17. This game does not currently have a GUI.
2. Connect 4: This game is a two player game where the goal is to get four elements in a row. Players alternate until someone wins.
3. Farkle: A dice game where any number of players up to ten can play. The goal is to get to 10000 points first. Detailed rules of Farkle can be found online, but the general gist is that you want to get sets of three or more, runs of six dice, three pairs, or fives and ones. This game does not currently have a GUI.
4. Gomoku: A board game where the goal is to get between three and sevent (usually five) tiles in a row before your opponent. Players alternate until someone wins. This game does not currently have a GUI.
5. Mastermind: A board game that is played solo (here). The computer randomly generates a code and the user tries to guess it. They get hints along the way that tell them how many pegs are correct or in the wrong place. This game has an unfinished GUI.
6. Risky Dice: A unique game based off of a dice game found on an old Flash website. This game is played with up to ten players, and the goal is to score as many points as you can while avoiding the "lose" die.
7. Yacht: A dice game played with up to a few players. Standard rules of Yacht can be found online, though this version is closer to Yachtzee. There's enough differences though that it still falls into Yacht, so I'm calling it that. This game does not have a GUI.
8. Poker: A card game played with up to six players. Rules are based on what you score. Each player scores points based on how good their hand is compared to the table.
Future game ideas include Flipper (Othello), Poker, Chess or Checkers, Battleship, and Backgammon.
